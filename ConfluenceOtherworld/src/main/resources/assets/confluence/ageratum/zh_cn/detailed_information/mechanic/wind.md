# 风

汇流来世的风参考了泰拉瑞亚：**风速随时间连续缓变，风向随位置变化**。

## 风速

- 风速使用国际单位 **m/s**（游戏内 1 方块 = 1 米）。
- 风速是**全局**的：同一时刻整个世界所有位置的风速大小一致。
- 风速不会突然改变，而是以大约 0.5 m/s 每秒的速率向目标值靠拢；目标值每隔 1~6 分钟重新抽取一次。
- 叠加了周期约 2~6 秒的**阵风**，所以读数会轻微地来回摆动。

### 档位

| 档位 | 风速（mph） | 风速（m/s） |
| --- | --- | --- |
| 静风 | 3 以下 | 1.34 以下 |
| 微风 | 3 ~ 10 | 1.34 ~ 4.47 |
| 有风 | 10 ~ 20 | 4.47 ~ 8.94 |
| 大风天 | 20 以上 | 8.94 以上 |
| 烈风 | 45 以上 | 20.12 以上（只会由事件或命令产生） |

mph 是**英里每小时**（1 mph = 0.44704 m/s），与本模组内部使用的 m/s 是同一套风速的两个单位。

**20 mph（8.94 m/s）是唯一影响玩法的阈值**：它既是「大风天」的门槛，也是大风天专属生物的出现条件。
其余档位只决定风粒子密度、云层速度与雨雪倾角。

## 风向

- 风向**取决于你所在的位置**：世界生成时的温度噪声场会让风在局部偏转，最多偏离全局风向 90 度。
- 因此同一个世界里，不同地区的风车可能指向不同方向；这也是为什么风速计要放在你想观测的地方。
- **方位的命名按气象学惯例，指的是风"从哪来"**：东风就是从东边吹来、吹向西方的风。
  真实风向标的箭头同样指向风来的方向，所以风向标与气象仪上的方位是一致的。
  命令 `/confluence wind set <x> <z>` 里的分量则是"吹向"，与方位名相差 180 度。
- 风向同样变化缓慢（约 4 度每秒），偶尔会整体转向甚至反向。

## 风会影响什么

| 对象 | 是否受影响 |
| --- | --- |
| 树叶、沙子、雪等方块与流体粒子 | 是（密度随风速增长，地下会衰减到没有） |
| 雨雪的倾斜 | 是 |
| 云层移动速度 | 是（静风时云几乎不动，大风天比原版更快） |
| 风速计、风车等装饰物 | 是 |
| **实体（掉落物、箭、生物、玩家）** | **平时完全不受影响** |
| 沙尘暴、暴风雪期间的实体 | 是，但**由这两个事件自己决定**（见下） |

## 大风天

- 出现条件：**白天**且风速达到 20 mph。
- 一旦出现会维持一段时间（风速被锁定在阈值以上），直到入夜或风速持续回落。
- 大风天专属的生物（瓢虫、风气球、愤怒蒲公英）只在这时出现；蝴蝶、臭虫、萤火虫则只在**非**大风天出现。

## 沙尘暴与暴风雪

这两个是**唯一**会让实体受风的天气事件，风系统本身不推任何实体。

- **沙尘暴**：沙漠中出现，要求风速达到 20 mph。期间风速被强制恒定（默认 30 mph）且**全场同向**
  （温度噪声造成的局地偏转会被关闭）。地表露天的非玩家实体会被风吹动；玩家顶着风走会明显变慢。
- **暴风雪**：雪原**下雨**时出现。**与风速无关**——暴风雪是「雪原中的雨」，不是「风大的雪」。
  雪原露天的实体会被吹动；在雪原里会听到暴风雪的风声（露天与室内是两种不同的音效）。

两个事件都可以在配置里关闭对实体的作用。

## 相关配置

风系统只有**视听表现**相关的选项放在**客户端配置**，影响玩法的都在通用（服务端）配置里。

通用配置（`Weather` 分类）：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `doWind` | 开 | 风系统总开关 |
| `windDirectionNoise` | 开 | 是否让温度噪声弯曲局地风向（关闭则为单一全局风向） |
| `windDirectionAmplitude` | 90 | 局地风向相对全局风向的最大偏转（度） |
| `windWindyChance` | 0.04 | 每次重抽到大风天档的概率（约每 7~8 个游戏日出现一次大风天） |
| `windSandstormForcedSpeed` | 13.41 | 沙尘暴强制风速（m/s） |
| `sandstormPushesEntities` / `blizzardPushesEntities` | 开 | 两个事件是否推实体 |

客户端配置（`Weather` 分类）：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `windSlantsRainClouds` | 开 | 风是否让雨雪倾斜、并驱动云层速度 |
| `blizzardAmbience` | 开 | 暴风雪是否播放环境风声（露天与室内为两种音效） |
| `showWindParticles` | 90 | 你能看见的风粒子数量（0~100 比例） |
