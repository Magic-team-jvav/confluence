# 魂师 · 测试版上手指南 & 测试须知

> 适用：1.21.1 / 1.20.1 两版（内容一致；按键与个别材料见文中标注）。默认你已经知道原版操作。

## 一、30 秒认识魂师

1. **两条资源互斥**：平时是魔力条；拿【堕魂星核】右键切成**灵魂模式**，再右键切回魔力。魂师技能只看灵魂，不看魔力。
2. **技能由主武器放**：手持魂师主武器（灯笼/残破微光一类）右键 = 施放当前选中的技能。
3. **缺魂要拿血顶**：灵魂不足时按 **1 点灵魂 = 4 点生命**代偿，会直接把人打死，所以施法前先看魂条。

## 二、五步上手

1. 合成【堕魂星核】：工作台无序 = 骨头 + 腐肉 + 坠落之星。
2. 右键星核 → 进灵魂模式，出现灵魂条。
3. 拿一把主武器（最便宜：地牢箱子的【残破微光】；或灯笼 + 星核做【领魂之灯】）。
4. 按 `Shift + C` 打开技能总览，把技能装进槽位（初始 3 个槽）。
5. 打怪补魂；想回魂就待在**灵雾/墓地**或**灵魂沙峡谷**（每秒回 5% 上限），或戴【灵魂手环】（每 3 秒 +1）；戴束魂锁链 / 手环系列 / 刻骨的记忆时，**每次收魂还额外 +1**。

## 三、界面与操作

| 操作 | 按键 / 方式 |
| --- | --- |
| 技能总览（看已解锁、装备技能） | `Shift + C`（可在按键设置里改） |
| 快捷切换技能 | 按住 `左 Shift` 开快捷面板 → 滚轮切换（大轮盘样式改为鼠标指向）→ 松开确认；需手持主武器 |
| 施放技能 | 主武器右键 |
| 灵魂/魔力切换 | 堕魂星核右键 |
| 快捷法器 | 数字键 1/2/3 选到法器槽即触发 |

- **魂术轮转**（被动）：施法后自动切到下一个不在冷却的技能；当前技能在冷却时按施法键，也会先跳到可用的技能再放。
- 技能槽初始 3 个，最多 6 个；冷却按技能共享，卸下重装不会清冷却。

## 六、技能解锁途径总览

- **初始就会**：引魂、强力附魂（不会自动装备）。
- **手持武器临时可用**：见主武器表。
- **技能书永久解锁**：见上表。
- **仪式解锁**：第 1 次：强力引魂、附魂印记、灵魂透支、魂术轮转、激荡系列（需先有灵魂激荡）；第 2 次：星魂逆转、星魂联结、灵魂收割；第 3 次：灵魂突击、噬魂借力；第 4 次：反噬抵抗、分魂驾驭、生命归还。
- **第一次拿到生机灿烂**：永久学会自然法则。

## 七、测试须知

这是**魂师测试版本**，请用创造模式快速拿物品测试：

- 创造标签页：**「汇流来世 | 魂师」**，分 主武器 / 副武器 / 法器（空） / 技能书 四组。
- 仪式结构尚未实装，目前只能用指令设置（见下）。
- 建议测试顺序：切灵魂模式 → 装 3 个技能 → 打怪看收魂与代偿 → 换套装/饰品 → 试技能书与仪式门槛。

## 八、测试指令（需 OP 权限等级 2，由玩家本人执行）

| 指令 | 作用 |
| --- | --- |
| `/confluence soulSkill reset` | 清空全部技能槽、当前索引归零、清空所有技能冷却；**不删**已永久学会的技能、临时可用状态和技能书记录 |
| `/confluence soulSkill slots <3~6>` | 设置技能槽数量。初始 3；第 1/3/5 次仪式会各 +1（3→4→5→6），此指令用于手动覆盖。增加时新槽为空，减少时裁掉超出部分 |
| `/confluence soulSkill ritual <0~6>` | 设置已完成的仪式次数。每次 +30 灵魂上限（最多 +180）；次数提高自动解锁对应门槛技能并追加技能栏位；次数降低会同步降低上限，把超出上限的当前灵魂压低 |

## 九、已知未完成

- 法器：没有成品内容。
- 仪式：没有世界结构，只能指令设置。
- 魂舞长袍套、收割者书、劫掠之道书、求生欲书：暂无正常获取途径（创造）。

## 十、第三批改动测试清单（本轮重点看这些）

### 10.1 魂引天星：按敌怪落星（齐射免费）

1. 创造模式拿【星魄】，右键开魂引天星（40→**80 秒**增益，施放耗 **15** 魂，冷却 **60 秒**）。
2. **落星规则**：每 10 刻扫一次 **48 格**内（球形距离）的敌怪，**每只敌怪头顶各落一颗**
   （按距离由近到远，每轮最多 **4 只**）；只与只之间相差 1 刻，能看到坠星"一阵一阵"错开落下。
3. **没有敌怪就不落**：站在空地上观察，增益期间头顶**一颗星都不落**（不会空转刷实体）。
   把怪引到 48 格内才重新开始落；同一个位置如果有 5 只以上的怪，只有最近的 4 只会被砸。
4. **一只怪只落一颗**：范围内只有 1 只敌怪时，每轮只有 1 颗星，不会 4 颗全砸同一只。
4. **额外齐射不消耗灵魂**：灵魂只在施放时扣 15，之后每轮都免费；灵魂条见底（0 魂）时照样落星。
5. 坠星伤害 6→**11**；落点在目标上方 8 格，若头顶是实心方块会向下找最近空位（洞穴里也能落出来）。

### 10.2 强力附魂系列 ×2 / +3

- 血怒：损血 **5**、+**200%** 近战/远程、持续 **16 秒**、冷却 3 秒 —— 可以直接常驻，看是否过强。

### 10.3 灵魂激荡：0.5 秒扩散到 6 格

- 放灵魂激荡，应看到冲击环**半秒内**从脚下扩到 6 格（旧版是 5 秒慢慢扩）。
- 强力激荡 8 格、灵魂激荡冲击的终结爆炸同样是 0.5 秒扩完。
- 注意：扩散很快 ⇒ 远端敌人几乎是"瞬间"被打，命中的是半径内全部目标，不再是慢慢扫过去。

### 10.4 引魂弹幕 / 引渡者 / 穿透 / 追踪

1. 基础引魂弹幕命中一只怪后，会**从那只怪朝附近另一只怪再射一发**；
   附近只有一只怪时朝随机偏移方向射出（表现为"打偏的一发"）。
2. 引渡者（鬼魂书）学成后：伤害 +**2**，且弹幕**再额外弹一次**。
3. **强力引魂**：在本体 1 次弹射之上**再 +1**（共 2 次）；若已学引渡者则共 **3 次**。
   观察方式：打一只怪，数它身上依次飞出的后续弹幕数量。
4. 颂魂指引：弹幕**穿透 2 个**敌怪继续飞；**穿透没打完之前不弹射**，穿透耗尽的那一下才弹射。
5. 带路的老前辈：弹幕会拐弯追最近的怪，**弹射出来的那一发也继续追踪**（弹射体继承追踪标记）。
6. 重点看密集怪群：弹射 + 连锁弹幕（灵魂引发 6 发）会互相叠加，确认帧率与手感。

3. 期间吃到增益（如强力附魂 +12%、复习）时伤害仍要提高 —— 快照只锁"武器基数"，增益照常实时结算。
4. 灵魂突击同理：增益期间换手，连射伤害不变。

### 10.5.2 灵魂长袍套装（灵魂头套 + 灵魂长袍）

- 只穿其中一件：只有单件自带的 +5%。
- **两件都穿**：套装效果再加 **+5%**（合计 +10% 灵魂伤害），看技能伤害行/实际伤害是否抬升。
- 脱掉任一件，加成立刻消失。

### 10.5.3 迷魂孢雾（本轮崩溃修复点）

1. 拿【松露灯】（手持授予迷魂孢雾）或装上该技能，连放几次。
2. 应该看到**淡绿色 7 帧孢子序列帧**从弹幕位置飘出并淡出；**不再有引魂的蓝色拖尾**。
3. 旧版崩溃日志：`run/crash-reports/crash-2026-10-21_22.56.41-client.txt`（ParticleStorm 的 fastutil 迭代器 NPE）。
4. 如果看到的还是蓝色拖尾，说明粒子 id 没同步（本轮已修：`DATA_PARTICLE`），把 `latest.log` 发我。

### 10.5.4 灵魂激荡的地面光环

1. 放一次灵魂激荡（普通 / 强力 / 终结爆炸都行）。
2. 应该在**脚底**出现一圈**平躺在 XZ 平面**的光环，从中心向外扩散，**0.5 秒**正好长到判定框边缘
   （普通 **7.2 格**半径 → 直径 14.4；强力激荡 / 终结爆炸 **9.6 格** → 直径 19.2）。
3. 透明度表现：出生瞬间**全透明**，很快**淡入**到清晰，中间保持清晰，最后约 1/6 秒**淡出到消失**。
4. 光环自身会有**缓慢的随机自转**（每次不一样）。
5. **只有这一层光环**：原来那 5 颗沿半径分布的蓝色灵魂粒子已经去掉，画面里不应再看到蓝色小点。

### 10.5.5 灵魂突击：子弹无粒子 + 枪械强化

1. 开灵魂突击增益，放技能：飞出的灵魂子弹**不应该有任何拖尾粒子**（纯判定体）。
2. 手持任意枪械（含霰弹枪）开火（需灵魂模式、灵魂 ≥ 1）：
   - 这一枪的子弹伤害 **+5**；
   - 魂条 **-1**；
   - **50%** 概率立刻**+1** 魂（多打几枪统计一下，大约一半的枪会返还）。
3. 灵魂为 0 时开枪：**不强化、也不掉血**，普通子弹照常打出。
4. 霰弹枪一次打出多颗弹丸：只扣 **1 魂**，所有弹丸都吃到 +5。

### 10.5.6 魂引天星降频

- 节奏：**2.5 秒一轮**（4 轮 / 8~12 秒的中间值），每轮只落 **2 颗**。
- 每轮仍然是最多 **2 只**最近敌怪各一颗，覆盖逻辑没变：
  80 秒增益里最多 **32 轮 × 2 = 64 颗**（旧版 256 颗）。
- 观察方式：站在 2 只怪旁边，数「一阵星 → 停顿约 2.5 秒 → 下一阵」，每阵只有 2 颗。

### 10.5.7 总览界面左下角的背景开关

1. `Shift + C` 打开技能总览，看**左下角**：⚙ 右边多了一个 **☑ / ☐** 小按钮。
2. 点一下 → `☐`：噪点、树、魔法、滚动全部停掉，只剩一层静态底色 + 技能节点/连线。
3. 再点一下 → `☑`：完整动态背景回来。
4. 悬停有提示；这个开关和 `选项 → 配置 → GUI → Soulcerer → 背景总开关` 是同一份配置，
   任一处改完另一处也同步。

### 10.5.8 切换灵魂技能按键（默认左 Alt）

1. 按键设置里现在只有一条相关绑定：**「切换灵魂技能」= 左 Alt**（原来「释放灵魂技能」那条已经合并掉）。
2. 手持魂师主武器，按住**左 Alt**：快捷技能面板弹出；滚轮切换选中技能；松开确认。
3. 把这条键改成别的键（比如 `V`），按住 `V` 同样能弹面板 —— 这就是旧版失效的地方（旧版改的是死绑定）。
4. 样式差异：
   - 小轮盘 / 横向卡片（左、右）：**滚轮切换**；
   - 大轮盘：**鼠标指向**切换（设计如此），滚轮对它无效。

### 10.5.9 强主动技能（灵魂透支 / 灭却业火 / 血怒）

这三个技能现在带 `confluence:major_active` 标签，效果是**只能手动施放**：

1. 戴【束魂锁链】并装上灵魂透支、血怒：用别的附魂技能时，**它们不会被一起放出来**。
2. 装【魂术轮转】并放附魂技能：连锁过程中**灵魂透支不会被带出**。
3. 连续放技能让轮转自动跳槽：选中位**不会停在**这三个技能上（它们也不会被"空槽时的施法键"顺手选中）。
4. 手动选中它们（轮盘 / 总览 / 数字键）后按施法键，照常释放。

> 「附魂」与「强力附魂系列」两个标签已合并成 `soul_attach`（11 个技能）。
> 所以束魂锁链 / 魂术轮转联动的名单**包含了灵魂突击**，连锁范围比其他附魂技能更大。

### 10.5.11 引魂激荡 / 灵魂激荡冲击（本轮重点）

**引魂激荡**（弹幕系，施放扣 3 魂）

1. 对着敌怪放一发：弹幕命中后，**敌怪脚下会扩散出一圈贴地光环**（就是灵魂激荡那个环），
   半径 3 格、0.5 秒扩散完；站在光环里的敌怪都会被再打一次。
2. 这发光环是**技能的衍生攻击，不消耗灵魂**：放之前看灵魂数，命中之后灵魂数不会再掉。
3. 引魂弹幕本身还会**弹射一次**：弹射出去的那一发命中的位置**同样会补一圈光环**
   （因此一次施放最多可能出现 2 圈）。
4. 光环的伤害 = 这一发弹幕的伤害（也就是**施法武器的快照伤害**，换手不会变）。

**灵魂激荡冲击**（3 次积攒 → 第 3 次额外终结爆炸）

1. 连续放 3 次：第 3 次除了常规激荡，还会额外炸一次**更大（9.6 格）、更痛（24）**的爆炸。
2. 这一炸会**把范围内的生物水平推开**，并附带一点向上位移。
3. **你自己不会被推走**（站在爆炸正中心也一样，位置不动）。
4. 普通灵魂激荡 / 强力激荡 / 引魂激荡**都不会击退**，只有这一次终结爆炸会。

### 10.8 堕魂星核：灵魂条 / 魔力条自动互切

1. **用一次**堕魂星核（切到任意模式都行）→ 解锁标记。
2. 之后拿魂师主武器右键：若当前在魔力模式，会自动切成**灵魂条**再施法。
3. 之后用任意魔法武器（法杖等）：若当前在灵魂模式，会自动切回**魔力条**。
4. 已知手感：切换会清空另一条资源（既有设计），所以"切过去的第一发"常常因为源池为空而打空，属预期。

- 关掉后：**保留一层静态深色底**（沿用色相/对比度），噪点、树、魔法、滚动全部停止；
  界面不会透出世界。
