## 一、30 秒认识魂师

1. **两条资源互斥**：平时是魔力条；拿【堕魂星核】右键切成**灵魂模式**，再右键切回魔力。魂师技能只看灵魂，不看魔力。
2. **技能由主武器放**：手持魂师主武器（灯笼/残破微光一类）右键 = 施放当前选中的技能。
3. **缺魂要拿血顶**：灵魂不足时按 **1 点灵魂 = 4 点生命**代偿，会直接把人打死，所以施法前先看魂条。

## 二、五步上手

1. 合成【堕魂星核】：工作台无序 = 骨头 + 腐肉 + 坠落之星。
2. 右键星核 → 进灵魂模式，出现灵魂条。
3. 拿一把主武器（最便宜：地牢箱子的【残破微光】；或灯笼 + 星核做【领魂之灯】）。
4. 按 `Shift + C` 打开技能总览，把技能装进槽位（初始 3 个槽）。
5. 打怪补魂；想回魂就待在**灵雾/墓地**或**灵魂沙峡谷**（每秒回 5% 上限），或戴【灵魂手环】（每 3 秒 +1）；戴束魂锁链 / 手环系列 / 刻骨的记忆时，**每次收魂还额外 +1**。

- **魂术轮转**（被动）：施法后自动切到下一个不在冷却的技能；当前技能在冷却时按施法键，也会先跳到可用的技能再放。
- 技能槽初始 3 个，最多 6 个；冷却按技能共享，卸下重装不会清冷却。

## 八、测试指令（需 OP 权限等级 2，由玩家本人执行）

| 指令                                 | 作用                                                                                                                                               |
|--------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| `/confluence soulSkill reset`        | 清空全部技能槽、当前索引归零、清空所有技能冷却；**不删**已永久学会的技能、临时可用状态和技能书记录                                                 |
| `/confluence soulSkill slots <3~6>`  | 设置技能槽数量。初始 3；第 1/3/5 次仪式会各 +1（3→4→5→6），此指令用于手动覆盖。增加时新槽为空，减少时裁掉超出部分                                  |
| `/confluence soulSkill ritual <0~6>` | 设置已完成的仪式次数。每次 +30 灵魂上限（最多 +180）；次数提高自动解锁对应门槛技能并追加技能栏位；次数降低会同步降低上限，把超出上限的当前灵魂压低 |

## 九、伤害与属性专项测试

本轮重点是区分武器基数、技能基数和灵魂属性倍率。武器提示受客户端 `weaponTooltipBaseStats` 控制：

| 显示模式         | 预期                                                 |
|------------------|------------------------------------------------------|
| 开启基础数值显示 | 武器基础伤害 + 当前技能基础伤害，不计玩家装备和增益  |
| 关闭基础数值显示 | 武器与技能合计伤害，经过技能修正后乘玩家灵魂伤害倍率 |

没有额外被动或事件修正时，公式是 **（武器伤害 + 技能伤害）×（1 + 灵魂伤害加成）**。例如星魄 11 + 引魂 5 =
16；25% 灵魂增伤时为 20，而不是 110。默认灵魂属性 1 已经代表 100%，不能再额外加 1。

- [ ] 无装备、无前缀与增益：悬停星魄，当前选引魂，应显示 16。
- [ ] 给玩家灵魂伤害 +25%：实际模式显示 20；切回基础模式仍为 16。
- [ ] 改变当前技能，伤害行随所选技能更新；空槽或无伤害技能只计武器基数。
- [ ] 手上拿另一件武器、悬停背包里的星魄：按悬停武器计算，不能混入当前手持武器伤害。
- [ ] 反复悬停不修改玩家属性、灵魂值、技能冷却，不残留临时修饰符。
- [ ] 武器暴击、攻速、前缀以及盔甲/饰品加成仍按原有规则显示。
- [ ] 同一敌怪、同一防御与难度下比较实际命中伤害；护甲、暴击、难度、通用减伤会影响最终掉血，不能直接拿掉血量当作未经减伤的提示值。
- [ ] 强力附魂、复习、灵魂徽章逐个验证；倍率只结算一次，不能把加成再次塞进武器基数。
- [ ] 用星魄施放魂引天星后换武器或空手：持续攻击的武器基数保持快照；后续增益变化仍按实时规则处理。

技能总览自身的“伤害”行仍是技能自身基数，不包含手持武器；不要与武器提示的合计伤害混淆。

## 十、功能回归清单

### 资源、生命代偿和学习

- [ ] 新玩家初始 3 槽；初始学会引魂和强力附魂，但不自动装备。
- [ ] 两种资源互斥；登录、复活、换维、重进存档后模式与成长份数正确。
- [ ] 灵魂刚好够、差 1、为 0 时分别施法；不足部分按生命代偿结算，检查死亡归因、无敌帧与吸收生命。
- [ ] 叠加生命条的代偿警示为淡蓝色；切技能、补魂或离开灵魂模式后复原。创造、空槽、被动、零消耗技能不警示。警示是预测，不保证自然法则随机减免后的实际扣血。
- [ ] 墓地和灵魂沙峡谷每秒恢复；同时满足不重复计环境恢复。
- [ ] 手持临时技能放下后不可再用，但槽位与冷却保留；永久学习记录不应消失。
- [ ] 技能被动必须装备才生效，卸下立即失效；引渡者是技能书被动，不占槽，两者分别测试。
- [ ] 读技能书首次学习、重复复习、前置不足、未绑定书分别测试；书不消耗。
- [ ] 刻骨的记忆只放行背包候选中的一个未永久学会技能，成功施法后重掷；移走候选武器或摘饰品后失效。

### 切换、轮转和联动

- [ ] 当前为空槽、被动或冷却技能时，施法入口按可用性跳到可释放技能；全部不可用则不施放。
- [ ] 魂术轮转及附魂连锁结束后的落点均跳过冷却技能；卸装、换槽和重复装备不清冷却。
