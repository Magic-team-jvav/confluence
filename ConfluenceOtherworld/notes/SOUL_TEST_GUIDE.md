更新日期：2026-10-22 批次。本文前半部分是**给玩家看的魂师介绍**，后半部分是**测试清单**。

## 一、魂师是什么

魂师是把**蓝条换成魂条**、用**主武器右键放技能**的职业。

1. **资源互斥**：默认是魔力条。用【堕魂星核】右键切成**灵魂模式**，魂师技能只看灵魂、不看魔力；再右键切回魔力。
2. **技能由主武器放**：手持魂师主武器（领魂之灯、残破微光一类）右键 = 施放当前选中的技能。
3. **缺魂拿血顶**：灵魂不足时 **1 点灵魂 = 4 点生命**代偿，会直接把人打死，施法前先看魂条。
4. **技能要解锁、要装槽**：开局只有 3 个技能、3 个槽；靠技能书、仪式、武器临时授予继续解锁，最多 6 槽。
5. **收魂靠击杀与套装**：击杀敌怪按最大生命/攻击/护甲收魂，Boss 直接回满；灵雾/墓地与灵魂沙峡谷每秒回 5% 上限。

## 二、五步上手

1. 合成【堕魂星核】：工作台无序 = 骨头 + 腐肉 + 坠落之星。
2. 右键星核 → 进灵魂模式，出现灵魂条。
3. 拿一把主武器：地牢箱子的【残破微光】，或工作台的【领魂之灯】。
4. `Shift + C` 打开技能总览，把技能装进槽位。
5. 打怪补魂；想慢慢回魂就待在灵雾/墓地或灵魂沙峡谷，或戴【灵魂手环】（每 3 秒 +1）。

## 三、操作与界面

| 操作 | 按键 / 方式 |
|---|---|
| 技能总览（看解锁、装技能） | `Shift + C`（可在按键设置改） |
| 快捷切换技能 | 按住 `左 Alt` 开快捷面板 → 滚轮/鼠标指向 → 松开确认（需手持主武器） |
| 施放技能 | 主武器右键 |
| 灵魂/魔力切换 | 堕魂星核右键 |
| 快捷法器 | 数字键 1/2/3 选到法器槽即触发 |
| 看技能说明 | 总览里把鼠标停在技能图标上（说明会盖在所有图标上层） |

- **魂术轮转**（被动）：施法后自动切到下一个不在冷却的技能；当前技能在冷却时按施法键会先跳到可用的再放。
- 冷却按技能共享，卸下重装不清冷却。
- **技能树排布**：中线左边是增益/被动，右边是伤害；最中间一列是开局技能，**越往外解锁越晚**（第 1~4 次仪式依次向外），
  同一竖列里是并列技能；有前置关系的技能之间才有连线，线一律由内向外指。
  这套排布写死在 `SoulOverviewScreen` 的节点表里；想先看效果/拖一版出来，用仓库根目录的
  `soul_tree_layout_editor.html`（浏览器打开，可拖拽与连线，并按 Java 表导出）。

## 七、本轮改动专项测试（重点）

- [ ] **迷魂孢雾**：连放 10 轮以上，确认有时整轮从**斜上方**抛出并下落、有时整轮**直线**飞出；
      孢子不应被追踪拐弯。
- [ ] **迷魂孢雾伤害公式**：单发应等于 `(武器伤害 × 20% + 1.5) × (1 + 灵魂增伤%)`。
      验证方法：同一只无护甲怪、同一难度下，换一把武器基数明显不同的主武器（如 11 与 5），
      单发掉血只应随「武器 × 0.2」变化；再把灵魂伤害属性提高 25%，掉血相应 ×1.25（只乘一次）。
- [ ] **引魂弱追踪**：对着偏一点的目标放引魂，弹幕应当**轻微**朝目标偏转而不是直冲固定方向；
      目标在身后时弹幕不会掉头；速度看起来不变。
- [ ] 手持**带路的老前辈**时追踪明显更强（原有词条仍然有效）。
- [ ] **灵魂激荡开局可用**：新建世界（或清过技能的老存档）进游戏，总览里灵魂激荡就是“已永久解锁”；
      老存档重进后同样应自动出现。
- [ ] **灵魂回响**：读《灵魂回响》后连放灵魂激荡 20~30 次，约 1/5 的次数会多出一圈激荡且**不额外扣魂**；
      开着附魂激荡时，自动激荡也应当偶尔翻倍；翻倍的那一圈不会继续无限翻倍。
- [ ] **附魂印记**：对一只怪放附魂印记后，
      - 它身上出现“附魂印记”debuff，持续 **10 秒**；
      - 期间用**任意技能**命中有 **+1 魂**（看魂条）；
      - 击杀它额外 **+2 魂**（与原本的击杀收魂叠加）；
      - 印记消失后不再回魂；
      - 施放附魂印记本身不再给玩家“强力附魂”buff。
- [ ] **灵魂缓冲**：使用后从高处落下不减血反而回血；增益消失后摔落伤害照常。
      旧书（改名前）仍可使用并显示为新名字。
- [ ] **收割者**：不再要求先学灵魂激荡，直接可用。
- [ ] **总览 tooltip 层次**：把鼠标停在**靠左/靠上**的技能图标上，说明文字必须完整显示在所有技能图标之上，
      不被相邻图标盖住；缩放 0.5~2 倍都成立。
- [ ] **描述对齐**：随机抽 5 个技能，对照第五节表格核对 tooltip 的伤害/耗魂/冷却/描述是否一致
      （重点看：引魂、附魂印记、迷魂孢雾、灵魂激荡、灵魂缓冲）。

## 八、通用回归清单

### 资源与学习

- [ ] 新玩家：3 槽、已解锁引魂 / 强力附魂 / 灵魂激荡，但不自动装备。
- [ ] 资源互斥；登录、复活、换维度、重进存档后模式与成长份数正确。
- [ ] 灵魂刚好够 / 差 1 / 为 0 时施法，代偿扣血与死亡归因正确；代偿警示条为淡蓝色。
